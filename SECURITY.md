# Security

Command Center runs agent CLIs that can read and write files on your PC. Please report security problems privately.

## Reporting

Use GitHub's **Report a vulnerability** button on the Security tab of this repository. Please do not open a public issue for a security problem.

Include what you found, how to reproduce it, and what an attacker could do with it.

## Scope

In scope: the local server (`server/`), the page (`public/`), the desktop shell (`electron/`) and the build scripts.

Out of scope: problems inside Claude Code, Codex, OpenCode or other agent CLIs themselves. Report those to their makers.
